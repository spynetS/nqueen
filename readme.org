The nqueen evolutionary algorithm is implemented in the [[file:nqueen.c][nqueen.c]] file.
The nqueen function inside the file is the entry point of the algorithm.
It takes config struct which contains the attributes controlling the algorithm.
The config struct is defined in [[file:nqueen.h][nqueen.h]].

If ROULETTE is defined the roulette wheel selection method will be used instead of the tournament selection

The [[file:testing.c][testing.c]] is a testing script that runs the algorithm x number of times (defined
int the file) in y rounds (also defined in the file) on different amount of Ns and calculcates the average
generations.


To compile
#+begin_src bash
make
#+end_src

To run
#+begin_src bash
make run
#+end_src

To plot the date from the testing
#+begin_src bash
make pyplot
#+end_src


To run python testing
#+begin_src bash
make pytest
#+end_src
